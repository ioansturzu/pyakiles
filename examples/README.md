# Numeric Simulations

This directory contains scripts to run and analyze numeric simulations using AKILES2D.

## Contents

- `potential_density.py`: Runs a simulation and plots potential and density profiles.
- `temperature_heatflux.py`: Runs a simulation and analyzes temperature/heat flux.
- `eedf_slices.py`: Runs a simulation and plots EEDF slices.
- `sims_*`: Output directories for simulations.
